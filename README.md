# cutest-picture-01 — Corgi Hugs a Chick

A 3D baby corgi in a knitted strawberry hat and pink scarf, hugging a
sleeping yellow chick, on a soft cream background. The cutest picture
entry for make.fun's cutest-picture-01 competition.

The corgi wears a hand-knitted red strawberry hat trimmed with white
daisies and a chunky pink scarf; the sleeping chick rests in its paws.
Verified deterministic: two runs of `main.py` produce byte-identical
output.

- `entry.png` — the picture (1024x1024, JPEG data, 182,523 bytes)
- `main.py` — a pure copy program: copies `entry.png` byte for byte to
  `MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`). Deterministic,
  no network, stdlib only.
